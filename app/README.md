# Wasla app (Flutter)

Generated in Phase 1 sprint 1 with:

```bash
flutter create --org app.wasla --platforms android,ios,web,windows,macos,linux --project-name wasla .
```

## Planned layout

```
app/
  lib/
    main.dart
    app/                  router (go_router), theme (light/dark), localisation bootstrap
    core/
      net/                ws_client.dart (Hello, RPC multiplexing, reconnect), connect_fallback.dart
      sync/               update_engine.dart (pts, gap buffer, GetDifference loop)
      db/                 Drift database (SQLCipher), tables, DAOs, FTS5 search
      outbox/             send queue, retry/backoff, random_id
      media/              compression, resumable upload manager, download cache
      push/               firebase_messaging, notification channels, mute
      l10n/               app_ar.arb (default), app_en.arb
      ui/                 design system; RTL-safe primitives only
    features/
      auth/               phone, code, 2FA password, sign-up
      chat_list/          dialogs, archive, pin, swipe actions, search
      chat/               conversation, composer, reply/forward/edit, multi-select, media viewer
      groups/             create, info, members, roles, invite links
      contacts/           phone-book sync, contact list
      profile/            my profile, username, photos
      settings/           privacy, sessions, notifications, theme, language, data usage, delete account
      report/             report and block flows
    gen/proto/            generated by `make proto-gen` (git-ignored)
  test/                   unit + widget tests; golden/ (ar-RTL and en-LTR × light/dark)
  integration_test/       Patrol end-to-end flows against staging
```

## Main packages (all permissively licensed; see ADR-009)

| Package | Use |
|---|---|
| flutter_riverpod | State management |
| go_router | Navigation |
| drift + sqlcipher_flutter_libs | Local database (encrypted) |
| protobuf | Generated messages |
| web_socket_channel | Transport |
| firebase_messaging | Push notifications |
| flutter_secure_storage | Session token in Keystore/Keychain |
| libphonenumber (plugin) | E.164 normalisation, default region IQ |
| video_compress, image | Media compression |
| record, just_audio | Recording and playing voice messages |
| flutter_map | Location messages; tile provider still to be decided |
